# Cyprus Post (ePost) services

Observed in the guest wizard on 2026-10-18; API codes from the Shipping Tool API PDF v1.0
(30 Sep 2026). Which services each destination allows: `services-by-country.json`.

## Services (wizard step 1)

| Wizard radio | Form value | API SKU | Limit | Tracked |
|---|---|---|---|---|
| EMS Datapost | `23` | `EMS` | 30 kg; length ≤ 1.5 m, sum of sides ≤ 3 m | yes |
| Letter, Small (P) | `1060150`, size `1` | `LTRSM` | 50 g | only with Registered or Recorded Delivery |
| Letter, Large (G) | `1060150`, size `2` | `LTRLG` | 500 g | only with Registered or Recorded Delivery |
| Letter, Irregular (E) | `1060150`, size `3` | `LTRIR` | 2 kg; L+W+H ≤ 900 mm, longest side ≤ 600 mm | only with Registered or Recorded Delivery |
| Parcel | `21` | `PRCL` | 30 kg; length ≤ 1.5 m, sum of sides ≤ 3 m | yes |
| A' Priority Parcels – Interconnect Premium | `24` | `INRCN` | participating countries only, goods only, signature on delivery | yes |

The letter size goes into `NC_ITEM_CATEGORY_ID` (1, 2 or 3); the other services put their form
value there. Letter is disabled above 2 kg gross. Size limits are from the public service pages
(https://www.cypruspost.post/en/epistoliko-taxidromeio-prodiagrafes,
https://www.cypruspost.post/en/demata-genika).

## Options (wizard step 2)

| Option | Product id | API code | Rule |
|---|---|---|---|
| A' Priority | 51 | `FRSPR` | preselected for letters |
| B' Priority | 52 | `SNDPR` | removed once Registered or Recorded Delivery is ticked |
| Registered (documents only for international) | 56 | `RGSTD` | requires nature `NDOCS` unless the destination is Cyprus |
| Advice of Delivery (AR) | 57 | `ADDAR` | |
| Recorded Delivery | 67 | `RCDLV` | removes Registered and B' Priority; the tracked choice for goods by letter |
| Insured value | 60 | `INSURED_AMOUNT` > 0 | forces Registered, so documents only internationally (ePost Manual) |
| Cash on delivery | 61 | `COD_AMOUNT` > 0 | forces Registered (ePost Manual) |

Every toggle is a server round trip (`CheckSelectedItemOption`, then `ReadItemOptions`) that
returns the new option list. EMS and Interconnect Premium have no options.

## Barcodes

The barcode is generated by the server at Create; guests cannot enter one. Format
`XY000000000ZZ`: R registered, L express, C parcel, CE premium parcel, E EMS, U untracked goods
(https://www.cypruspost.post/en/faq-track-trace). The prefix of a Recorded Delivery letter is not
published.
